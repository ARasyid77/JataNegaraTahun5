# Jelajah Jata Negara

An interactive Sejarah Tahun 5 learning game about the Malaysian Coat of Arms.

Play online: https://arasyid77.github.io/JataNegaraTahun5/

## Run

Open `Jelajah Jata Negara.html` in a modern web browser. The game loads Three.js from the Cloudflare CDN, so an internet connection is needed when opening the page.

GitHub Actions publishes the game to GitHub Pages whenever a change is pushed to `main`.
